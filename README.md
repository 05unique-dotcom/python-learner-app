# Python Learner

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fpython-learner--05unique7057.replit.app&up_message=online&down_message=offline&label=live%20site)](https://python-learner--05unique7057.replit.app)

Interactive Python learning platform with lessons, quizzes, badges, a certificate of completion, streak tracking, a points & rewards system, and a real leaderboard.

## 🚀 Live Website

**[Open Python Learner →](https://python-learner-app-python-learner-y-ten.vercel.app)**

No installation needed — just click the link above and start learning Python directly in your browser.

## Features

- 📘 Structured lessons (variables, loops, functions, OOP, and more) with interactive quizzes
- 🏅 Badges earned automatically as you progress
- 🔥 Daily streak tracking
- ⭐ Points & Rewards system — earn points for lessons, quizzes, streaks, and course completion, and unlock Bronze/Silver/Gold Keys and a Champion Prize
- 🏆 Real leaderboard ranking actual learner points
- 🎓 Certificate of completion
- ⚡ Quick Challenge mode for fast practice
- 🌗 Dark / light mode

## Tech Stack

- pnpm workspaces monorepo, Node.js, TypeScript
- Frontend: React + Vite
- Backend: Express 5
- Database: PostgreSQL + Drizzle ORM
- API contract: OpenAPI + Orval codegen
