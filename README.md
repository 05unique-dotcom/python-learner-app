 # 🐍 Python Learner

An interactive Python learning platform designed to make learning Python simple, engaging, and practical.

Learn Python through structured lessons, interactive quizzes, badges, streaks, rewards, challenges, and a real-time leaderboard.

## 🚀 Live Website


[Python-learner-app_Live demo](https://python-learner--arshadansari786.replit.app/)

**No installation required.** Open the website and start learning Python directly in your browser.

---

## ✨ Features

- 📚 **Structured Python Lessons**
  - Variables
  - Loops
  - Functions
  - Object-Oriented Programming
  - And more

- 🧠 **Interactive Quizzes**
  - Test your knowledge after learning each topic.
  - Earn points by completing quizzes.

- 🏅 **Badges & Achievements**
  - Automatically earn badges as you progress.

- 🔥 **Daily Streak Tracking**
  - Maintain your learning streak and stay consistent.

- ⭐ **Points & Rewards System**
  - Earn points for:
    - Lessons
    - Quizzes
    - Daily streaks
    - Course completion

- 🏆 **Leaderboard**
  - Compete with other learners.
  - Track rankings based on learner points.

- 🎓 **Certificate of Completion**
  - Receive a certificate after completing the course.

- ⚡ **Quick Challenge Mode**
  - Complete short challenges for fast Python practice.

- 🌙 **Dark / Light Mode**
  - Switch between dark and light themes.

- 🎁 **Reward System**
  - Unlock Bronze, Silver, and Gold keys.
  - Work towards the Champion Prize.

## 📖 How It Works

The learning experience is designed around learning, practicing, and rewarding progress.

1. 📚 Learn a Python concept.
2. 🧠 Take an interactive quiz.
3. ⭐ Earn points.
4. 🏅 Unlock badges.
5. 🔥 Maintain your daily streak.
6. 🏆 Improve your leaderboard ranking.
7. 🎓 Complete the course and earn your certificate.

---

## 🎯 Goal

The goal of **Python Learner** is to make Python education more interactive and motivating.

Instead of only reading theory, learners can learn concepts, practice questions, track their progress, earn rewards, and build consistency while learning Python.
